# Code audit — 3-phase power telemetry dashboard (v9)

## Executive assessment

This codebase is a **client-side 3-Phase Power Telemetry Dashboard** (React 18 + HTM + Chart.js 4 + PapaParse 5 + Tailwind CSS) that ingests CSV exports from industrial electrical data loggers (such as Janitza UMG 96 PQL, Secure Elite 440, and Elspec G4K/trend exports) and visualizes 3-phase voltages, currents, 4-quadrant power triangle (`kW`, `kVAR`, `kVA`, signed/magnitude `PF`), voltage/current unbalance (`VUF%`, `IUF%`), neutral current (`I_N`), frequency (`Hz`), and trapezoidally integrated energy (`kWh`, `kVArh`, `kVAh`).

The v9 review resolved the remaining open header-mapping collisions, phase-scheme ambiguities, CSV delimiter false positives on European decimal-comma files, unreachable empty-column status reporting, unity-PF overshoot scaling, and UI/chart lifecycle issues.

## Summary of bugs found and fixed in v9

| \# | Bug / Issue | Root cause in uploaded code | Fix implemented in v9 | 
| ----- | ----- | ----- | ----- | 
| 1 | **Bare `VA` header collision** | `PAT` matched `va` in `VR` (index 5) before `kVA` (index 16), so a Volt-Ampere apparent power column named `VA` was mis-mapped to Phase-A voltage (`VR`) and `kVA` was lost. | Added `isPhaseAVoltageHeader()`: bare `va` maps to `VR` only when explicitly formatted as a phase voltage (`V_A`, `V-A`, `VA (V)`) or accompanied by a `Vb` + `Vc` triplet; otherwise `VA` maps to `kVA` with `×0.001` scaling. | 
| 2 | **R/Y/B vs A/B/C phase ambiguity (`Vb`/`Vc` & `IB`/`IC`)** | `VY` did not match `vb`, while `VB` matched both `vb` and `vc` (mapping `Vb` to Phase 3 and dropping `Vc`). Meanwhile, `IY` matched `ib`, stealing `IB` whenever `IB` appeared before `IY` or `IY` was absent in an R/Y/B file. | Added `detectPhaseScheme(fields)` (`PAT_ABC` vs `PAT_RYB`) to inspect the whole header set: in A/B/C files, `A/B/C → Phases 1/2/3`; in R/Y/B files, `R/Y/B → Phases 1/2/3` without `IY` matching `IB`. | 
| 3 | **European decimal-comma CSV delimiter mis-detection** | `repairCsvText()` scored candidate delimiters (`;`, `\t`, `,`) using only data rows (`sample`). In a `;`-delimited file where every number uses a decimal comma (`225,5;226,1;...`), `,` appeared more times per data row than `;`, causing `,` to win. | Scored delimiters against `Math.min(headCount, dataMin)` and required `headCount >= 1`, ensuring the delimiter appears consistently in both the header and data rows. | 
| 4 | **Unreachable `'empty'` signal status & placeholder shadowing** | In `normalize()`, `imported = !!map[sourceKey] && !!hasData[map[sourceKey]]` made the `'empty'` branch (`imported ? (present ? 'imported' : 'empty') : ...`) unreachable whenever `hasData` was `false`. Also, `hasData` treated placeholder strings (`"---"`, `"OL"`) as valid data. | Tracked `hasData` (non-blank) and `hasNumData` (valid `toNum(v) != null`) separately; restored reachable 4-state status (`imported`, `estimated`, `empty`, `missing`) in both `normalize()` and `refreshImportReport()`. | 
| 5 | **Unity PF overshoot divided by 100 (`1.002 → 0.01002`) & `-0` PF** | `derive()` scaled any \` | PF | 
| 6 | **Multi-token suffix stripping in `norm()` & device-prefixed `headerUnit()`** | `norm()` stripped only one trailing unit/qualifier token (leaving `Current L1 RMS A` with `rms`), and `headerUnit()` did not strip `Device > ` prefixes before checking standalone units (`Dev A > VA`). | Added a 2-pass suffix stripper in `norm()` that stops cleanly once a phase header is reached, and stripped `Device > ` prefixes in `headerUnit()`. | 
| 7 | **Timestamp parser (`pt`) & Date+Time combination** | `pt()` treated nanosecond epochs (`>1e17`) as microseconds, rejected stringified epoch numbers (`"1700000000"`), and misread Excel serial dates (`20000–100000`). `normalize()` only combined `map.t` + `map.clock` when `norm(map.t) === 'date'`. | Added nanosecond epoch (`>1e17`), stringified epoch, and Excel serial date support in `pt()`, and combined `map.t` + `map.clock` whenever `map.t` lacks a clock time (`:`). | 
| 8 | **Time-window preset off-by-one & mid-parse stale settings closure** | `pickPreset()` used `Math.round(i / n * 100000)`, which floored down to `i - 1` when converted back via `Math.floor(win[0] / 100000 * n)`. `handle()` captured stale `topology`/`assumeBalanced` values during async worker parse. | Used `Math.ceil` in `pickPreset()`, read latest settings via `cfgRef.current` in `handle()`, and added automatic fallback to `worker: false` if Web Worker creation fails. | 
| 9 | **`PowerChart` hidden-series markers, tooltip blank lines & memoization** | `PowerChart` still drew `S peak` and `Q min/max` markers when `kVA` or `kVAR` was hidden via legend toggles; `label: () => ''` inserted blank lines in the tooltip; un-memoized `datasets`/`opts` re-updated all charts on every state change. | Filtered extrema markers by `!hidden.kVA` / `!hidden.kVAR`, returned `null` from `tooltip.callbacks.label`, guarded `c.tick?.value === 0`, made `r._source` non-enumerable, removed dead `PfCard`/`durationText` code, and memoized chart datasets/options. | 
| 10 | **Duplicate `@media` rules in `styles.css` & Delta voltage gauge fallback** | `styles.css` had duplicate `@media (min-width: 768px)` and `@media (min-width: 1280px)` blocks for `.power-stats-grid`; Delta voltage gauges had `altKey={undefined}` when `VRY/VYB/VBR` were absent and estimation was disabled. | Consolidated responsive grid rules in `styles.css` and added `VR/VY/VB` fallback keys on Delta voltage gauges. |
